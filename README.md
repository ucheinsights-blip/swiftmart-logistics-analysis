# swiftmart-logistics-analysis
Excel dashboard analyzing SwiftMart's delivery operations — revenue by location, top-selling items, and vehicle performance.

SwiftMart Logistics Analysis
Excel-based analysis of SwiftMart's delivery and logistics operations, covering transactions, outlet performance, and delivery status.

Contents
Raw transaction data (item, cost, weight, outlet, delivery status)
Pivot tables: revenue by location, top-selling items, item rankings
Insights: pending deliveries, high-value items (>₦50,000), service fees by office, vehicle types by weight capacity
Interactive dashboard with KPIs

Tools
Microsoft Excel (Pivot Tables, Dashboards, KPIs)

File
